# Buscador_Sombras
Aplicación móvil que proporciona a peatones y ciclistas rutas para llegar a sus destinos tales que estas minimizan la exposición solar. Además, ayuda a los conductores a localizar aparcamiento de manera que mientras el coche esté aparcado reciba la mayor cantidad de sombra en zonas cercanas a las facultades de UCM.
